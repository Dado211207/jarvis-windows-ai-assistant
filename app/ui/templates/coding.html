Coding Workspace

A separate mode for working on your own code projects. It does nothing until you add a project, and it can only reach files inside the project folder you choose.

You are in Coding Workspace. JARVIS can read and change files in the project you select, and run that project's own development commands. It cannot reach anything outside the project folder, and it never reads the files that hold your credentials — the exact list is at the bottom of this page. Chat on the other pages has none of these powers.
