Personality Memory

What JARVIS remembers about your preferences. Saved only when you ask — e.g. remember that I prefer short answers. Stored locally in SQLite; never sent anywhere. Secrets are never stored.

JARVIS never collects memory silently. Nothing here is inferred from ordinary chat — every entry was saved by an explicit request. Deleting is never immediate: click Forget then Confirm delete to remove a single item here (or Cancel to keep it), or say forget <text> to confirm on the Actions page. To wipe everything, say clear memory — that also requires confirmation on the Actions page. Passwords, API keys, tokens, cookies, and browser data are never stored.
