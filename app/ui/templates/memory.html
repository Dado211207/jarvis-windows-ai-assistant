Personality Memory

What JARVIS remembers about your preferences. Saved only when you ask — e.g. remember that I prefer short answers. Stored locally in SQLite; never sent anywhere. Secrets are never stored.

JARVIS never collects memory silently. Nothing here is inferred from ordinary chat — every entry was saved by an explicit request. Delete a single item with its Forget button, or say forget <text>. To wipe everything, say clear memory — that is a destructive action and requires confirmation on the Actions page. Passwords, API keys, tokens, cookies, and browser data are never stored.
