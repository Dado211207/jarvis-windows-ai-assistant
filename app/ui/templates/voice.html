Capabilities
  • ✓ Text-to-speech output (pyttsx3 / SAPI5)
  • ✓ This engine is output only — it never captures audio
  • ✓ Push-to-talk voice input (mic button on the Chat page)
  • ✓ No wake word or always-listening, ever
  • ✓ No cloud TTS or cloud STT — local engines only
  • ○ Wake word / continuous listening — planned for a later phase
Controls

Enable/Disable sends speak on / speak off through the JARVIS command router. Test speaks a short phrase aloud. Stop interrupts current speech immediately.

JARVIS Phase 3 implements text-to-speech output only using the local pyttsx3 engine (Windows SAPI5 / Linux espeak); TTS failures never crash the app — audio errors are logged and the app continues normally. Separately, v0.2 adds push-to-talk voice input on the Chat page (also local — no cloud STT). Push-to-talk needs a local speech model — install one (with license, size, and checksum shown first) from the Setup page. Wake-word detection and always-listening behavior remain planned for a later phase and are not present in this build.
