Welcome to JARVIS

A few quick things and you're ready — none of them required, and all of them changeable later in Settings.

Optional. Leave it blank and JARVIS won't use a name.

Stored in the Windows credential store, never in a file, and never shown again. JARVIS tries it against Anthropic first: a key Anthropic rejects is not saved, and one that can't be checked right now — you're offline, or rate-limited — is saved and marked unconfirmed.

Status …

Leave this blank first. A key scoped to a single workspace when you created it needs no ID at all — that includes a key scoped to your Default Workspace, and it is the simplest setup. If Anthropic rejects the key asking for a workspace, come back and fill this in: non-default workspaces are listed in the ID column of Settings → Workspaces in the Claude Console. The Default Workspace is not listed there — Anthropic returns its ID in the anthropic-workspace-id header of any response from a request that runs in it.

Without a key, JARVIS still runs commands, opens allowlisted apps, takes notes and reports system status — it just can't answer open questions.

Everything else is optional

  • Voice input and spoken replies are set up on the Voice page.
  • A local AI provider, startup behaviour and privacy mode live in Settings.
  • Nothing leaves this machine unless you configure a cloud provider above.
