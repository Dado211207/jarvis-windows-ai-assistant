Welcome to JARVIS

JARVIS is a local assistant for Windows. It runs on your machine, answers questions, and can perform a small set of carefully limited Windows actions.

  • Ask questions and run commands by typing, or by holding the microphone button.
  • Anything that touches your machine in a meaningful way asks for approval first.
  • Every action is recorded in a local history you can review at any time.

This takes about a minute. You can skip any optional step and come back later from Setup in the sidebar.

Your data stays on this machine

  • The JARVIS server listens on 127.0.0.1 only. It is not reachable from your network.
  • Conversations, memories and action history are stored in a local SQLite file.
  • Nothing is uploaded anywhere unless you configure a cloud AI provider in the next step.
  • Privacy mode stops new conversations and memories being saved at all.

Honest limitation: the local database is a plain file, not an encrypted vault. Anyone with access to your Windows account can read it. JARVIS does not claim otherwise.
