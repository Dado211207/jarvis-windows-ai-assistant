Help & Setup

Getting started with JARVIS.

Quick Start

  1. Start JARVIS API: run START_JARVIS_API.bat or python -m app.api.server
  2. Open this dashboard: http://127.0.0.1:5555/ui/
  3. Use the Chat page to send commands and questions
  4. (Optional) Add your Anthropic API key to .env for AI responses
  5. (Optional) Enable TTS on the Voice page

Adding Your API Key (Optional)

JARVIS works without an API key. All deterministic commands work locally. To enable Claude AI responses:

  1. Copy .env.example to .env
  2. Open .env in a text editor
  3. Add your key: ANTHROPIC_API_KEY=your-key-here
  4. Restart JARVIS

Your API key is stored only in .env on your machine. It is never sent to this browser, never committed to git, and never included in builds.

Commands

  • helpList all available tools
  • statusShow JARVIS version and config
  • system statusCPU, RAM, disk, battery
  • open <app>Launch an allowlisted app (chrome, notepad, calculator…)
  • screenshotCapture screen to data/screenshots/
  • memory add <text>Save a note to local memory
  • memory search <query>Search saved memories
  • speak onEnable TTS voice output (session only)
  • speak offDisable TTS voice output
  • speak statusShow TTS engine status
  • speak testSpeak a test phrase aloud
  • stop speakingStop current speech immediately
  • exitExit JARVIS CLI

API & Docs

The local API runs on http://127.0.0.1:5555 and is never exposed to the network.

Open Swagger API Docs ↗

● Local-only
JARVIS binds exclusively to 127.0.0.1. It is not accessible from other devices on your network. Your API key, memories, and conversation history never leave your machine. Arbitrary command execution and password extraction are permanently blocked by the permission system.
