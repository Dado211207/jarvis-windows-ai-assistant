Help & Setup

Getting started with JARVIS and a full command reference.

Quick Start
  1. You're already looking at the dashboard — no setup needed to get here
  2. Use the Chat page to send commands and questions
  3. (Optional) Add an Anthropic API key on the Settings page for Claude AI responses
  4. (Optional) Enable TTS on the Voice page
API Key Setup (Optional)

JARVIS works without an API key — all deterministic commands are local. To enable Claude AI natural-language responses:

  1. Open Settings and find the AI Provider section
  2. Paste your Anthropic API key and click Save key
  3. It's validated with Anthropic, then stored securely — no restart needed

Your API key is never shown here in full, never sent anywhere except Anthropic (only to validate it and generate replies), and never stored as plain text: `.env` during development, or Windows DPAPI-encrypted storage in the installed app. See docs/SECURITY.md for the full model.

Commands — General
  • helpList all available tools
  • statusShow JARVIS version and config
  • exitExit JARVIS CLI
Commands — System Info
  • system statusCPU, RAM, disk, battery summary
  • disk spaceShow disk usage (used / free / total)
  • network statusShow hostname and local IP (read-only, no scanning)
  • battery statusShow battery level and power status
  • screenshotCapture screen to data/screenshots/
Commands — Open Apps & URLs
  • open <app>Launch an allowlisted app (notepad, calculator, chrome, vscode…)
  • open file explorerOpen Windows File Explorer
  • open settingsOpen Windows Settings
  • open website <url>Open an http/https URL in your default browser
  • open dashboardOpen the JARVIS local dashboard in the browser
Commands — Open Folders
  • open downloadsOpen your Downloads folder
  • open documentsOpen your Documents folder
  • open desktopOpen your Desktop folder
  • open notes folderOpen the JARVIS Notes folder
  • open jarvis folderOpen the JARVIS project folder
Commands — Notes & Memory
  • create note <text>Save a timestamped note to ~/Documents/JARVIS_Notes/
  • memory add <text>Save a freeform note to local SQLite memory
  • memory search <query>Search saved freeform notes
Commands — Settings (Phase 8)
  • settingsShow current settings (also: show settings)
  • set my name to <name>Tell JARVIS what to call you
  • set assistant name to <name>Rename the assistant
  • set language to <language>Set your preferred language
  • set response style to <short|balanced|detailed>Set preferred answer length
  • set tone to <friendly|formal|casual|neutral|direct>Set preferred tone

Settings persist across restarts in your local database. Edit them visually on the Settings page. Secrets and API keys are never stored here.

Commands — Personality Memory (Phase 8)
  • remember that <text>Explicitly save a preference (also: save preference <text>)
  • what do you rememberList saved preferences (also: show memory)
  • search memory <query>Search personality memory
  • forget <text>Delete a single saved preference
  • clear memoryDelete ALL preferences — requires approval on the Actions page

JARVIS only saves memory when you explicitly ask — never silently, never from ordinary chat. Manage entries on the Memory page.

Commands — Voice (TTS)
  • speak onEnable TTS voice output (session only)
  • speak offDisable TTS voice output
  • speak statusShow TTS engine status
  • speak testSpeak a test phrase aloud
  • stop speakingStop current speech immediately
Approval-Required Actions
  • clear logsDelete all action log entries — requires confirmation on the Actions page

Approval-required commands create a pending action. Use the Actions page to confirm or cancel. Pending actions expire after 10 minutes.

Permanently Blocked

The following are blocked by the permission system and will never execute:

  • Arbitrary shell / CMD / PowerShell commands
  • Arbitrary executable paths (apps not in the allowlist)
  • File deletion or mass file operations
  • Windows Registry edits
  • Dangerous URL schemes (file:, javascript:, data:, powershell:)
  • Folders not in the allowlist
  • Password or credential extraction
  • Keylogging, clipboard snooping, or screen surveillance
  • Network scanning or port scanning
Never Stored in Memory or Settings

Settings and personality memory are for safe preferences only. JARVIS refuses to save the following — the value is rejected and nothing is written:

  • Passwords, passphrases, and PINs
  • API keys (Anthropic, OpenAI, GitHub, Netlify, and others)
  • Access / auth tokens and private keys
  • Cookies and browser session data
  • Contents of your private files

There is no hidden monitoring: nothing is inferred and saved automatically, and no screen, browser, microphone, or file scanning takes place.

Planned (Not Yet Implemented)
The following features are planned for future phases and are not present in this build:
  • OCR / screen intelligence (planned, on-request only)
  • Browser automation (planned, approval-gated)
  • Microphone input / speech-to-text / push-to-talk (planned)
  • Wake word detection (planned)
  • Smart home and health integrations (planned)
API & Developer Docs

The local API runs on http://127.0.0.1:5555 and is never accessible from other devices on your network.

Open Swagger API Docs ↗

Local-only
JARVIS binds exclusively to 127.0.0.1. It is not accessible from other devices on your network. Your API key, memories, and conversation history never leave your machine. Arbitrary command execution and credential extraction are permanently blocked by the permission system.
